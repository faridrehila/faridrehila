### 🚀 Products I build and run

#### 💌 [Love Album](https://love-album.com?ref=github)
**Wedding photo sharing via QR code. Guests add photos without installing anything.**
- 📊 8,000+ albums created, 227,000+ photos, 100+ weddings per season
- 📱 Web, iOS and Android, sold in France, Germany and Belgium
- 🧩 Live slideshow (SSE), audio/video guestbook, in-app QR card editor, auto-generated printed photo books
- 🧪 Pricing and paywall A/B tests, PostHog funnels, Stripe + RevenueCat
- 💻 Next.js, React Native/Expo, Postgres/Prisma, Backblaze B2, Hetzner + Coolify, Cloudflare

#### 💼 Joeb (ex-Easy Job Room)
**Job-search tracker for unemployed people in Switzerland**
- 🎯 Saves every application as you share it, then reports it to job-room.ch at the end of the month
- 🤖 LLM assistant that drafts cover letters and prepares interviews
- 📱 iOS, Android, Chrome and Firefox extensions

#### 🧘‍♀️ BookZen
**Booking SaaS for Swiss yoga studios**, co-founded with a yoga teacher
- Classes, memberships, 10-class cards, waitlists, video on demand, FR/DE/EN
- 💻 Cloudflare Workers, Postgres, Stripe

#### 🧑‍💻 [React Académie](https://rn.reactacademie.fr?ref=github)
React and React Native courses (Udemy + YouTube), followed by several hundred students.
